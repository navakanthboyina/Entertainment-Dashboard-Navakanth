# Entertainment Dashboard - Navakanth

A public entertainment dashboard by Navakanth for discovering and launching **free and legal entertainment sources** across movies, TV, music, radio, podcasts, audiobooks, games, documentaries, and education.

## Live Site

https://navakanthboyina.github.io/Entertainment-Dashboard-Navakanth/

## Categories

- 🎬 Movies & TV
- 🎵 Music & Radio
- 🎙️ Podcasts & Audiobooks
- 🎮 Games & Interactive
- 🧠 Documentaries & Education

## Features

- Direct links to free and legal entertainment platforms
- Bookmark-ready search terms
- Built-in filtering/search
- Mobile-friendly responsive layout
- One-click shortcuts for frequently used sources
- No paid subscription required for the core dashboard
- No piracy or unofficial streaming sources

## Tech Stack

The current version intentionally uses:

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

This keeps the project fast, lightweight, easy to maintain, and dependency-free.

## Repository

https://github.com/navakanthboyina/Entertainment-Dashboard-Navakanth

## Deployment

The site is hosted with **GitHub Pages** from this repository.

The root `index.html` is the main dashboard entry point.

A `.nojekyll` file is included so GitHub Pages serves the project as a plain static site without Jekyll processing.
